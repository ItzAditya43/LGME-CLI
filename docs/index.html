What it does

Everything between "I have a game" and "I'm playing it."

Linux can run most Windows games, but setting it up by hand means Proton versions, prefixes, environment variables and log files. LGME does that part for you.

One command adds any game

Point it at a ZIP, 7z, RAR or TAR archive (split ones too), a folder you've already unpacked, a setup.exe installer, or a direct download link you trust. LGME unpacks it, finds the program that starts the game, and asks you only when it's unsure.

$ lgme add ~/Downloads/Cool-Game.7z ✓ Unpacked the archive ✓ Added 'cool-game'. → Play it with: lgme cool-game

A menu, no commands to learn

Type lgme and choose from a numbered list. To add a game, drag its file or folder into the terminal window.

Sets up your PC

lgme setup checks Steam, Proton, Wine, graphics drivers and disk space. It installs what's missing after asking you first.

Steam games, too

Paste a Steam store link and LGME asks Steam to install the game, then launches it alongside your other games.

Explains crashes

If a game closes early, LGME reads its log and tells you the likely cause, such as a missing DLL or graphics driver, and the command that fixes it.

Proton first, Wine as backup

Windows games run with GE-Proton when you have it. lgme setup downloads the latest release from its official GitHub page and verifies the checksum. Every game gets its own Windows environment (a prefix), so one game can't break another.

Type the name, play the game

lgme cool-game starts it. LGME can also create a command so that typing just cool-game works, and add the game to your app menu next to your other apps.

Keeps your saves

Already have a game folder with its own prefix? LGME finds it and reuses it, so your saves and settings come along.

Feather-light

One small Python file with no background process. While you play, LGME sleeps and uses no CPU. Logs are capped at a few MB. It updates itself with lgme update.

Never deletes without asking

It won't overwrite a game, folder, prefix or command you already have, and it refuses archives that try to write outside their folder.

The guide

From a fresh install to playing, in four steps.

You only do steps 1 and 2 once. After that, adding and playing a game takes one command each.

01

Install LGME

Open a terminal (search for "Terminal" or "Konsole" in your app menu), paste this line and press Enter. It puts the lgme command in ~/.local/bin. If your system doesn't look in that folder yet, the installer shows you the one line to fix it.

$ curl -fsSL https://github.com/ItzAditya43/LGME-CLI/releases/latest/download/install.sh | sh
02

Get your PC ready

Run setup. It checks everything games need, then offers to fix each missing piece. Nothing is installed until you say yes. Package installs ask for your password.

$ lgme setup
LGME setup check ✓ Steam: steam ✓ GE-Proton: GE-Proton11-6 ✓ Wine: wine-11.21 ! winetricks: not installed ✓ Graphics (Vulkan): AMD Radeon Install winetricks? [Y/n]
  • Steam, Wine, winetricks, 7-Zip come from your distro's package manager (pacman, apt, dnf or zypper), or Steam from Flathub.
  • GE-Proton, the best way to run Windows games, is downloaded from its official release and checked before installing.
  • Graphics: if your Vulkan driver is missing, it tells you which one to install for AMD, Intel or NVIDIA.
03

Add a game

Use lgme add with whatever you have. It works out what kind of thing it is. Not sure? Pick below to see exactly what to type and what happens.

Unpack and add an archive

ZIP, 7z, RAR and TAR all work. For split archives (.part1.rar, .001), keep every part in the same folder and add the first one.

  1. LGME suggests a short name, like cool-game.
  2. It checks you have enough free space, then unpacks into ~/Games/LGME/.
  3. It finds the game's program and skips helpers like crash reporters and redistributables.
  4. Your original archive is left alone.
$ lgme add ~/Downloads/Cool-Game.zip
Name for this game [cool-game]: Unpacking Cool-Game.zip into ~/Games/LGME/cool-game ✓ Unpacked the archive ✓ Added 'cool-game'. Start it by just typing 'cool-game'? [Y/n] Add it to your app menu? [Y/n]

Add a folder that's already unpacked

The game stays exactly where it is. LGME only remembers where it is.

  1. If several programs could start the game, you pick from a numbered list.
  2. If the folder already has a prefix (for example prefix/pfx), LGME offers to reuse it, keeping your saves.
  3. Removing the game later never deletes this folder.
$ lgme add ~/Games/Cool-Game
Found several programs. Which one starts it? 1. CoolGame.exe [Windows] (recommended) 2. Tools/Editor.exe [Windows] Found an existing Windows environment (prefix) at ~/Games/Cool-Game/prefix. Use it? [Y/n] ✓ Added 'cool-game'.

Run a Windows installer

Works for an installer .exe on its own, or inside an archive.

  1. LGME makes a fresh Windows environment just for this game.
  2. The installer window opens. Click through it and keep the suggested folder.
  3. When it finishes, LGME finds the installed game and adds it.
$ lgme add ~/Downloads/setup_cool_game.exe
This is a Windows installer. → Click through the installer and keep the suggested install folder. Running the installer with Proton (GE-Proton11-6)… ✓ Added 'cool-game'.

Install through Steam

Copy the game's Steam store link (or just the number in it) and paste it. You need to own the game on your Steam account.

  1. Steam opens its install window. Click Install.
  2. If it's already installed, LGME simply adds it.
  3. lgme steam list shows everything already installed in Steam.
$ lgme steam add https://store.steampowered.com/app/413150/Stardew_Valley/
✓ Added 'stardew-valley' and asked Steam to install it. → Steam will open an install window. Click Install. → When it's installed: lgme stardew-valley

Download from a link you trust

Use a direct link to the archive file, such as one from a developer's itch.io or GitHub page.

  1. If the download stops, run the same command again and it resumes.
  2. If the link opens a web page instead of a file, LGME tells you to download it in your browser and add that file.
  3. After a successful unpack, the downloaded archive is removed to save space.
$ lgme add https://example.com/cool-game.zip
Downloading: 64% 1.2 GB of 1.9 GB 38 MB/s ✓ Downloaded 1.9 GB ✓ Unpacked the archive ✓ Added 'cool-game'.
04

Play

Type lgme and the game's name. If you said yes to the shortcut, typing just the name works too, or you can click it in your app menu. The first launch takes a minute while the game's Windows environment is set up.

$ lgme cool-game
$ lgme list # all your games
Starting Cool Game with Proton (GE-Proton11-6)… (Game messages are saved to a log. Close the game to come back here.) ✓ cool-game closed. Played for 47 min.
When it breaks

Plain-English help, not a wall of logs.

When a game closes early, LGME reads the game's log and points you to the fix. These are the most common situations.

What you seeTry thisWhy
"The game is missing Windows files: msvcp140.dll"lgme fix cool-game vcrun2022Installs the Microsoft runtime the game expects, using winetricks.
Game closes instantly, no hintlgme logs cool-gameShows the last messages and what they might mean. Also check protondb.com.
LGME started the wrong programlgme set cool-game --pick-exeChoose again from the list.
Works badly with Protonlgme set cool-game --runner wineSome older games prefer plain Wine. Use --runner auto to switch back.
"prefix looks broken"lgme set cool-game --new-prefixStarts a fresh Windows environment. The old one is kept, so saves aren't lost.
"Vulkan support seems missing"lgme doctorYour graphics driver needs Vulkan. The check says which driver to install.
"That link opens a web page, not a file"lgme add ~/Downloads/file.zipDownload it in your browser first, then add the file.
Game uses EasyAntiCheat / BattlEyeCheck protondb.comAnti-cheat often blocks Linux unless the developer turned support on.
Why LGME

The same result, without the homework.

LGME isn't magic. It does the same steps experienced Linux gamers do by hand, in the right order, every time.

Setting it up by hand

  • Find, download and unpack the right Proton build yourself
  • Write a launch script full of environment variables for every game
  • Keep track of which prefix belongs to which game
  • Read raw Wine logs to work out why a game won't start

With LGME

  • lgme setup installs and verifies GE-Proton for you
  • lgme add, then type the game's name to play
  • One prefix per game, created and remembered automatically
  • Crash hints that name the fix, like lgme fix … vcrun2022

LGME downloads games only from Steam or from links you give it. It has no game catalog or store of its own. Use sources you trust.

FAQ

Common questions.

I've never used a terminal. Can I still use this?

Yes, that's who it's for. Open "Terminal" or "Konsole" from your app menu and paste the install line. After that, type lgme and choose from the menu. To add a game you can drag its file into the terminal window instead of typing the path.

Which Linux distros does it work on?

Any distro with Python 3.9 or newer, which is nearly all of them. lgme setup can install the extra tools automatically on Arch (and Manjaro, EndeavourOS, CachyOS), Ubuntu, Debian, Mint, Pop!_OS, Fedora and openSUSE. On other distros it tells you which packages to install.

Do I need Steam?

No. Steam is only needed for Steam games. Everything else runs with GE-Proton or Wine, and lgme setup can install GE-Proton without Steam.

Will it delete my games or saves?

Not without asking. Removing a game takes it off your list. Game files are deleted only if LGME unpacked them and you say yes. A game's prefix, which is where saves usually live, is deleted only if LGME created it and you say yes. Folders you added yourself are never deleted.

Does every Windows game work?

Most do, thanks to Proton, but not all. Games with anti-cheat that blocks Linux usually won't. Check the game on protondb.com, where other players share what works.

Where does LGME get games from?

Only from Steam, or from files and direct links you give it. It has no game catalog and doesn't bypass any store.

How do I update or uninstall it?

Update with lgme update. To uninstall, run rm ~/.local/bin/lgme && rm -r ~/.local/share/lgme/app. Your games, saves and settings stay where they are (~/Games/LGME, ~/.local/share/lgme, ~/.config/lgme).
